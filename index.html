merkle-seal --help

Seal a set of files. Later, see exactly which one changed.

Every file becomes a leaf of a Merkle tree and one 32-byte root seals the set. Each file carries its own inclusion proof, so verification pins a change to the file that caused it, and the root can be signed to prove who sealed it.

  • SHA-256 + ECDSA P-256 via Web Crypto
  • domain-separated leaves and nodes
  • parallel hashing in Web Workers
  • no uploads: the page blocks all network requests
