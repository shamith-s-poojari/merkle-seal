Merkle.Seal Shamith S Poojari

Prove a set of files has not changed

Hash a folder of files into a single Merkle root. Later, check the same files against that root: if anything changed, this tells you exactly which file, and shows the cryptographic path that proves it.

Nothing leaves your machine. Files are read and hashed locally with the Web Crypto API. There is no server, no upload, and no analytics.
